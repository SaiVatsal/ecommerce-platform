# Project 01: Full-Stack E-Commerce Platform (KRONOS)

A high-performance technical e-commerce platform built with **React + Vite + TailwindCSS + Zustand** and a **Stripe test-mode** simulation engine.

## 🎨 Distinct Visual Identity
- **Palette**: Pure black & white base with electric lime-green accent (`#84cc16` / `#a3e635`).
- **Typography**: Oversized sans-serif headings with high-density monospace telemetry & badges.
- **Layout**: Architectural card-grid catalog, slide-over drawer, and high-contrast dashboards.

## 🚀 Full Feature Set Included
- **Multi-role Auth Simulation**: Switch instantly between **Customer**, **Seller**, and **Admin** modes from the top bar.
- **Product Catalog with Variants & Filters**: Category pills, live price range filter, variant selector (size, finish, color).
- **Cart & Secure Checkout**: Cart bag drawer, quantity management, express shipping, and simulated Stripe test-mode checkout.
- **Real-Time Order Tracking**: Multi-step order tracking stepper (*Placed* → *Processing* → *In Transit* → *Out for Delivery* → *Delivered*).
- **Downloadable Invoices**: One-click generation and download of formatted order tax invoices.
- **Seller Inventory Studio**: Stock manipulation (+/- quick stock actions), item registration, and live inventory table.
- **AI Product Photography Suite**: Simulated AI image generation hook for sellers publishing products without custom media.
- **"Customers Also Bought" Engine**: Dynamic cross-sell recommendation engine inside product modal view.
- **Reviews & Community Ratings**: Verified star ratings, review submission, and aggregated scores.
- **Saved Wishlist Vault**: Persistent collection of monitored artifacts.
- **Executive Admin Analytics**: Gross revenue, units shipped, customer churn rates (1.8%), and top-performing product leaderboards.

## 🛠️ How to Run
```bash
npm install
npm run dev
```
